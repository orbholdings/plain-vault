# Security policy

Plain Vault 0.1.0 is an experimental preview. An independent security audit and
physical Windows/Android validation have not been completed. Use test credentials
until those checks are complete. There is no production security support guarantee.

## Reporting a vulnerability

Use the repository's **Security → Report a vulnerability** option if private
vulnerability reporting is enabled. If that option is unavailable, open an issue
asking the maintainer for a private reporting channel, without exploit details.

Do not put working exploits, real vaults, passwords, pairing codes, tokens or
private keys into a public issue. A report should describe the affected version,
impact and reproduction steps using dummy data once a private channel is agreed.

See [PRIVACY-AND-SECURITY.md](PRIVACY-AND-SECURITY.md) for the security design and
limitations, and [VALIDATION.md](VALIDATION.md) for completed and outstanding checks.
